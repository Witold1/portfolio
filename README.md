A portfolio website built with Next.js, Tailwind CSS, and Docker, deployed to GitHub Pages.

## Setup

Ensure Docker Desktop is installed and running.

**Development** (live reload via `next dev`):

```bash
docker compose -f docker/docker-compose.dev.yml up --build
```

**Production preview** (static export served by Nginx - rebuild after changes):

```bash
docker compose -f docker/docker-compose.prod.yml up --build -d
```

Or build/run the prod image directly:

```bash
docker build -f docker/Dockerfile.prod -t my-next-app-prod .
docker run -p 3000:80 my-next-app-prod
```

Access at `http://localhost:3000/my-portfolio-test/` (dev and prod).

Docker Desktop’s port link always opens `http://localhost:3000/` (it does not know your `basePath`). Prod Nginx redirects that to the full URL; bookmark `/my-portfolio-test/` if you use the link often.

The production Docker image serves static files from `out/` (generated by `next build` with `output: 'export'`). Nginx is configured to mirror the GitHub Pages `/my-portfolio-test/` path locally. GitHub Pages deployment does not use Docker or Nginx - see [GitHub Pages Deployment](#github-pages-deployment) below.

**Switching dev ↔ prod:** stop one before starting the other (both use port 3000):

```bash
docker compose -f docker/docker-compose.dev.yml down
docker compose -f docker/docker-compose.prod.yml up --build -d
```

## Content Engine

- MDX content root: `content/` (see `content/_README.md` for layout)
- Blog posts: `content/blogposts/*.mdx` -> `/blog` and `/blog/[slug]`
- Project posts: `content/projects/*.mdx` -> `/projects` and `/projects/[...slug]`
- Gallery data: `content/gallery/items/*.yaml` + `config/gallery-settings.json` (build-time via `lib/gallery/loadItems.js` on `/gallery`)
- Site config (e.g. popular posts order): `config/popular-posts.json`

## Pages

- `/` Home
- `/about` About
- `/blog` Blog listing
- `/projects` MDX project listing and project detail pages
- `/gallery` Gallery
- `/sitemap` Sitemap
- Missing URLs: `pages/404.js` → `out/404.html` (used by GitHub Pages, GitLab Pages, and similar static hosts when `basePath` matches your deploy)

## Features

Responsive navigation bar with Gallery link, light/dark mode toggle (fixed-size button), mobile menu for small screens, and branded logo ("Witold's Data" in monospace).
Footer with left-aligned Sitemap link and legal note, uniform font size, and no margin between Sitemap and legal note.
Consistent page titles in format " - Witold's Data Consulting".
Blog-style Projects section with dynamic post pages (/projects/[...slug]) via shared MDX detail shell.
Tailwind CSS styling with lazy-loaded media and dark mode support (including filter buttons).
Client-side routing with Next.js.
Static site export for GitHub Pages.
Modal images and carousel on Home page and blog posts using external URLs.
Scalable gallery with multi-category filtering, larger cards, modal close button in viewport corner, and close on background click.
Navbar and Footer rendered globally via pages/_app.js for consistency.

Git Setup

Initialize Git and add `.gitignore`:
```bash
git init
git add .
git commit -m "Initial commit"
```


Push to GitHub:
```bash
git remote add origin https://github.com/Witold1/my-portfolio-test.git
git push -u origin main
```



GitHub Pages Deployment

Update next.config.js with basePath: '/my-portfolio-test' and assetPrefix: '/my-portfolio-test/'.
Ensure .github/workflows/deploy.yml grants contents: write and pages: write permissions.
Push to GitHub:
```bash
git add .
git commit -m "Deploy to GitHub Pages"
git push origin main
```


Enable GitHub Pages in Settings > Pages with Deploy from a branch and select gh-pages.
Access at https://Witold1.github.io/my-portfolio-test/.

Troubleshooting

404 Error: Ensure Settings > Pages uses gh-pages branch. Verify out/ files in gh-pages.
403 Permission Error: Grant “Read and write” permissions in Settings > Actions > General.
Links Not Updating: Ensure basePath matches repo name. Check out for index.html files.
CSS Missing: Verify tailwind.config.js, postcss.config.js, and out/_next/static/css/.
Images Not Loading: Confirm `src` URLs in `content/gallery/items/*.yaml` (or your CDN base in `config/gallery-settings.json` / `NEXT_PUBLIC_MEDIA_BASE_URL`).
Theme Issues: Check DevTools Console for theme toggle logs. Ensure dark class toggles on <html>.
Footer Issues: Ensure only one footer appears; verify pages/_app.js includes <Footer /> and pages do not.
Build Errors: Check pages/projects/[...slug].js for correct file paths in getStaticPaths and getStaticProps.
