A portfolio website built with Next.js, Tailwind CSS, and Docker, deployed to GitHub Pages.

## Features

### Blog and projects

Content lives in `content/` as MDX with YAML front matter. Both collections share the same reading experience:

- **Rich MDX** — table of contents, footnotes, collapsible sections, code snippets, image carousels, and media grids
- **Publishing metadata** — dates, tags, featured posts, WIP banners, and optional `hidden` drafts (preview via `/admin`)
- **Citations** — per-page citation box with copyable BibTeX and plain text
- **Share and discuss** — social links plus “Discuss with AI” shortcuts (ChatGPT, Claude, Perplexity, Gemini)

### Gallery

Visualizations are one YAML file per item in `content/gallery/items/`:

- Category filters, grid or list layout, uniform or variable card sizing, and pagination
- Lightbox for images, video, and multi-slide carousels — open state is a shareable `?item=` URL
- Media files live in the separate [witold1-blog-assets](https://github.com/Witold1/witold1-blog-assets) repo; YAML and MDX reference CDN-relative keys

### Site-wide

- Light, dark, or system theme with responsive navigation
- Open Graph titles in the form `… - Witold's Data Consulting`
- `/admin` page for local-only prefs: show hidden content, toggle a debug panel, pick date calendar style

### Build and deploy

- Static export (`output: 'export'`) with `basePath` `/portfolio/` for GitHub Pages
- Docker Compose for live-reload dev and an Nginx preview of the production static tree

## Content Engine

- MDX content root: `content/` (see `content/_README.md` for layout)
- Blog posts: `content/blogposts/*.mdx` → `/blog` and `/blog/[slug]`
- Project posts: `content/projects/*.mdx` → `/projects` and `/projects/[...slug]`
- Gallery data: `content/gallery/items/*.yaml` + `config/gallery-settings.json` (loaded at build via `src/lib/gallery/loadItems.js`)
- Site config: `config/popular-posts.json`, `config/home-mosaic.json`

Media files are not stored in this repo. Set `mediaBaseUrl` in `config/gallery-settings.json` (or `NEXT_PUBLIC_MEDIA_BASE_URL`) and keep CDN-relative keys in YAML/MDX.

## Pages

- `/` — Home (intro, mosaic, pipeline)
- `/about` — About / contact
- `/blog` — Blog index (tags, featured vs chronological)
- `/blog/[slug]` — Blog post
- `/projects` — Project listing
- `/projects/[...slug]` — Project write-up
- `/gallery` — Visualization gallery
- `/sitemap` — HTML sitemap
- `/admin` — Local browser preferences (not indexed)
- Missing URLs → `src/pages/404.js` → `out/404.html`

## Setup

Ensure Docker Desktop is installed and running.

**Development** (live reload via `next dev`):

```bash
docker compose -f docker/docker-compose.dev.yml up --build
```

**Production preview** (static export served by Nginx — rebuild after changes):

```bash
docker compose -f docker/docker-compose.prod.yml up --build -d
```

Or build/run the prod image directly:

```bash
docker build -f docker/Dockerfile.prod -t my-next-app-prod .
docker run -p 3000:80 my-next-app-prod
```

Access at `http://localhost:3000/portfolio/` (dev and prod).

Docker Desktop’s port link always opens `http://localhost:3000/` (it does not know your `basePath`). Prod Nginx redirects that to the full URL; bookmark `/portfolio/` if you use the link often.

The production Docker image serves static files from `out/` (generated by `next build` with `output: 'export'`). Nginx mirrors the GitHub Pages `/portfolio/` path locally. GitHub Pages deployment does not use Docker — see below.

**Switching dev ↔ prod:** stop one before starting the other (both use port 3000):

```bash
docker compose -f docker/docker-compose.dev.yml down
docker compose -f docker/docker-compose.prod.yml up --build -d
```

## GitHub Pages

`next.config.js` sets `basePath` and `assetPrefix` to `/portfolio`. The workflow in `.github/workflows/deploy.yml` needs `contents: write` and `pages: write`.

```bash
git push origin main
```

In the GitHub repo: **Settings → Pages → Deploy from a branch → `gh-pages`**.

Live site: [https://witold1.github.io/portfolio/](https://witold1.github.io/portfolio/).

## Troubleshooting

- **404:** Settings → Pages should use the `gh-pages` branch. Confirm `out/` files landed there.
- **403 on Actions:** grant Read and write in Settings → Actions → General.
- **Links ignore `basePath`:** `basePath` must match the repo name; check `out/` for `index.html` under each route.
- **CSS missing:** verify `tailwind.config.js`, `postcss.config.js`, and `out/_next/static/css/`.
- **Images missing:** `src` in `content/gallery/items/*.yaml` should be CDN-relative keys; check `config/gallery-settings.json` / `NEXT_PUBLIC_MEDIA_BASE_URL`.
- **Theme:** stored preference vs system; `dark` class should toggle on `<html>`.
- **Duplicate footer:** only `src/pages/_app.js` should render `<Footer />`.
- **Build errors on projects:** `src/pages/projects/[...slug].js` `getStaticPaths` / `getStaticProps` must match files under `content/projects/`.
