Transcultural Empire (Peoplespace) dataset explorer - map and table views over 1897 / 1926 census units

What is this about?

From Russian Empire subjects to Soviet citizens, this project illustrates population change with the 1897 and 1926 censuses via maps and tables.

The Imperial census asked about social estate, native language, and religious affiliation. The Soviet census asked about self-declared nationality (narodnost) - and native language (not included in this extract). Backbone GIS comes from Sablin et al., doi:10.11588/DATA/10064.

Stack

Vite + TypeScript explorer (MapLibre, VisQuill); Python prep (pyshp, shapely) rebuilds data/processed/ GeoJSON, dictionaries, and tables from the Sablin shapefiles.

Further census context: Explanatory Notes (1926) and the List and Dictionary of Nationalities (1927) via Demoscope Weekly.
