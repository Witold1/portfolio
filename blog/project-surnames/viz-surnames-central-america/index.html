Some description about "raster vs vector" formats, georeferencing in general and current geo-referencing for vector images.

Raster files are images built from pixels - tiny color squares that form detailed images. More pixels = higher quality.

Vector files use mathematical equations (lines and curves), so they scale without losing quality.

See:

adobe com/creativecloud/file-types/image/comparison/raster-vs-vector

Georeferencing (or georegistration) is the process of aligning spatial data (raster or vector) to real-world coordinates.
