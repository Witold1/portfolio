## What is this about?

This is a **meta-post** to ease navigation across surname wordcloud visualizations by world region.

Political boundaries are mostly shown according to their “de facto” status<FootnoteRef id="ref 1" />.
Raw data came from [Forebears.io](https://forebears.io/).

## FAQ

<CollapsibleSection title="How to read these wordcloud maps?" level={2} defaultOpen={false}>
  The bigger the word, the more frequent the surname. Wordclouds are built from aggregated surname frequencies by administrative unit.
  
  
  Interactive reference example: <a className="mdx-link" href="https://gallery.pyecharts.org/#/WordCloud/wordcloud_diamond" target="_blank" rel="noreferrer">Apache ECharts wordcloud demo</a>.
